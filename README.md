# ciinder

Biến tài liệu học thành bài trắc nghiệm và thẻ ôn tự luận, chơi ngay trên trình duyệt, chia sẻ bằng link hoặc tệp HTML.

Mở app: https://harieedawwn.github.io/ciinder/

## Cách dùng với AI
1. Tải tệp hướng dẫn [`ciinder-guide.md`](https://harieedawwn.github.io/ciinder/ciinder-guide.md).
2. Gửi tệp đó cùng tài liệu học (bài giảng, đề cương, ảnh chụp…) cho AI bất kỳ (ChatGPT, Gemini, Claude…) và nhờ soạn bộ câu hỏi theo hướng dẫn.
3. Sao chép toàn bộ văn bản AI trả về, mở ciinder, chọn Dán nội dung.
4. Học, làm bài kiểm tra, rồi chia sẻ link hoặc tải tệp HTML để gửi cho bạn bè.

Dữ liệu chỉ lưu trên máy bạn (không có máy chủ). Dùng Sao lưu trong Cài đặt để chuyển sang máy khác.

## Phát triển
```bash
npm install
npm run dev
npm run verify
```
